Exclusive Mart - Modern E-Commerce Platform

Exclusive Mart is a production-ready, full-stack e-commerce web platform engineered with React 18, TypeScript, Vite, Node.js, and MongoDB Atlas. It features distinct customer and admin interfaces alongside real-time communication.

Key Features:

  • Real-Time Product Chat: Customers can initiate instant live chats with store admins regarding specific products, powered by Socket.IO.
  • Comprehensive Catalog & Cart: Dynamic product browsing, smart search filters, cart management, and order placement.
  • Dedicated Admin Panel: Secured with a 16-digit access code for catalog management, live inventory tracking, order status updates, and multi-user chat support.
  • Cloud Storage: Images and files stored securely via Microsoft Azure Blob Storage.
