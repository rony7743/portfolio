Multipurpose AI Platform

This is a modern AI-powered web platform built with Next.js 15, TypeScript, and Tailwind CSS, integrating cutting-edge LLMs including OpenAI api.

Key Capabilities:

  • AI Content & Email Generation: Generate high-quality articles, marketing copy, and professional emails in seconds.
  • Image & Media Creation: Create and manipulate images using integrated multimodal AI models.
  • Authentication & Security: Seamless social sign-in powered by NextAuth and Google OAuth.
  • Modern UI/UX: Clean dashboard interface built with Tailwind CSS, supporting dark/light aesthetics and responsive mobile-first layouts.
